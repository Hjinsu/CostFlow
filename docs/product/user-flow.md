# 사용자 흐름

## 전체 흐름

`기초 데이터 설정 → 원재료·부품 등록 → 공급가격·환율 관리 → BOM 구성 → 원가 계산 → 견적 생성 → 결과 저장·조회`

## 1. 기초 데이터 설정

관리자는 회사의 기본 계산 환경을 설정합니다.

- 기준 통화
- 환율 적용 방식
- 기본 부대비용 항목
- 소수점과 반올림 기준
- 기본 마진 계산 방식

## 2. 공급처와 원재료·부품 등록

구매 또는 원가 담당자는 다음 정보를 등록합니다.

- 공급처
- 품목 코드와 품목명
- 구매 통화
- 공급 단가와 적용 시작일
- 단위와 최소 주문 수량
- 관세율, 운임 등 기본 부대비용 정보

가격이 변경되면 기존 값을 덮어쓰지 않고 유효 기간을 가진 새 가격으로 저장합니다.

## 3. 환율 입력

사용자는 견적에 적용할 환율과 기준일을 지정합니다.

- 통화
- 환율
- 기준일
- 출처 또는 메모

MVP에서는 환율 자동 수집 없이 수동 입력을 기본으로 합니다.

## 4. 제품과 BOM 구성

제품을 등록한 후 원재료·부품의 소요량을 BOM에 연결합니다.

- 제품 코드와 제품명
- 구성 품목
- 단위 소요량
- 손실률
- 선택적 제조 간접비

## 5. 제조원가 계산

사용자는 계산 기준일과 적용 환율을 선택해 원가를 계산합니다.

1. BOM별 외화 공급가격을 기준 통화로 환산합니다.
2. 수량과 손실률을 적용합니다.
3. 운임, 보험, 관세 등 부대비용을 반영합니다.
4. 필요하면 제조 간접비를 더합니다.
5. 품목별 결과를 합산해 제품 제조원가를 계산합니다.

계산 화면은 합계뿐 아니라 품목별 산출 근거를 보여줍니다.

## 6. 견적가 산출

제조원가에 마진 정책을 적용합니다.

- 목표 마진율 입력
- 계산된 견적가 확인
- 필요 시 최종 견적가 수동 조정
- 조정 사유 기록

## 7. 견적 저장과 출력

견적을 저장할 때 계산에 사용된 값을 스냅샷으로 남깁니다.

- 고객과 견적 번호
- 작성일과 유효기간
- 적용 환율
- 원가 구성
- 목표 마진과 최종 가격
- 메모

저장된 견적은 조회하고 PDF 또는 엑셀로 출력할 수 있습니다.

## 주요 예외 흐름

- 필수 가격이나 환율이 없으면 계산을 중단하고 누락 항목을 표시합니다.
- BOM에 단위가 호환되지 않으면 사용자 확인을 요구합니다.
- 견적가를 수동 조정하면 조정 사유를 필수로 기록합니다.
- 과거 견적은 최신 데이터로 자동 변경하지 않고 당시 스냅샷을 유지합니다.
