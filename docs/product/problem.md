# 문제 정의

## 해결하려는 문제

수입 원재료와 부품을 사용하는 제조사의 원가·견적 업무는 공급가격, 통화, 환율, 운임, 관세, 기타 부대비용과 BOM을 함께 반영해야 합니다. 그러나 많은 조직에서 계산 기준과 데이터가 여러 엑셀 파일과 담당자의 기억에 흩어져 있습니다.

## 현재 업무 방식

1. 공급처의 견적서나 이메일에서 단가와 통화를 확인합니다.
2. 담당자가 임의의 환율 또는 최근 고시 환율을 입력합니다.
3. 운임·보험·관세 등 부대비용을 별도 파일에서 찾습니다.
4. 제품별 BOM 수량과 손실률을 적용해 원가를 계산합니다.
5. 목표 마진이나 관행적인 가산율로 판매 견적을 만듭니다.
6. 결과를 엑셀이나 PDF로 전달하고 개별 폴더에 보관합니다.

## 핵심 불편

- 계산에 사용한 가격과 환율의 기준 시점을 알기 어렵습니다.
- 파일마다 수식과 비용 항목이 달라 결과가 일관되지 않습니다.
- 운임, 관세, 손실률 등의 누락이 늦게 발견됩니다.
- 공급가격이나 환율이 바뀔 때 영향받는 제품을 다시 계산하기 어렵습니다.
- 과거 견적의 산출 근거를 복원하고 비교하는 데 시간이 걸립니다.
- 업무 지식이 특정 담당자에게 집중됩니다.

## 문제의 영향

- 원가 과소 계산으로 수익성이 악화될 수 있습니다.
- 원가 과대 계산으로 가격 경쟁력을 잃을 수 있습니다.
- 견적 작성과 승인에 시간이 오래 걸립니다.
- 고객 문의에 계산 근거를 빠르게 설명하기 어렵습니다.
- 담당자 변경 시 동일한 업무 품질을 유지하기 어렵습니다.

## CostFlow의 접근

CostFlow는 입력 데이터, 계산 규칙, 결과 이력을 분리해 관리합니다. 각 견적은 사용한 공급가격, 환율, BOM, 부대비용과 마진 정보를 스냅샷으로 남기며, 동일한 규칙을 반복 실행할 수 있게 합니다.

## 해결하지 않는 문제

초기 제품은 회계 전표 처리, 구매 발주, 재고·생산 계획, ERP 전체 기능을 대체하지 않습니다. 원가와 견적 계산의 정확성·속도·추적 가능성에 집중합니다.
