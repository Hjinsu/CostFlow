# MVP 범위

## MVP 목표

수입 원재료 기반 제조사가 하나의 제품에 대해 계산 근거가 남는 제조원가와 견적가를 만들고, 이후 다시 조회할 수 있는 최소한의 완결된 흐름을 제공합니다.

## 포함 기능

### 조직과 기본 설정

- 단일 조직
- 기준 통화 설정
- 반올림 기준 설정
- 기본 마진 계산 방식 설정

### 공급처 및 품목 관리

- 공급처 등록·수정·조회
- 원재료·부품 등록·수정·조회
- 품목별 구매 통화와 단위 관리
- 공급가격과 적용일 관리

### 환율 관리

- 통화별 환율 수동 등록
- 환율 기준일과 메모 저장
- 계산 시 적용 환율 선택

### 제품과 BOM

- 제품 등록·수정·조회
- 제품별 BOM 구성
- 품목별 소요량과 손실률 입력

### 원가 계산

- 외화 공급가격의 기준 통화 환산
- BOM 수량과 손실률 반영
- 운임, 보험, 관세 등 부대비용 반영
- 선택적 제조 간접비 반영
- 품목별·제품별 원가 내역 표시

### 견적

- 고객 기본 정보 입력
- 목표 마진 기반 견적가 계산
- 최종 가격 조정과 사유 기록
- 계산 입력값과 결과 스냅샷 저장
- 견적 목록·상세 조회
- PDF 또는 엑셀 출력

## MVP 제외 기능

- 실시간 환율 자동 수집
- ERP·회계·구매 시스템 연동
- 구매 발주, 입고, 재고 관리
- 생산 계획과 작업 지시
- 복잡한 다단계 승인 워크플로
- 세분화된 역할·권한 체계
- 다법인·다국가 세무 처리
- AI 가격 예측과 최적 가격 추천
- 고객 포털과 전자서명
- 모바일 전용 앱

## 핵심 사용자 스토리

- 원가 담당자로서 공급가격과 환율을 적용해 제품 제조원가를 계산하고 싶다.
- 구매 담당자로서 품목 가격 변경 이력을 관리하고 싶다.
- 영업 담당자로서 목표 마진을 반영한 고객 견적을 만들고 싶다.
- 관리자로서 견적에 사용된 계산 근거와 과거 이력을 확인하고 싶다.

## MVP 완료 기준

- 사용자가 샘플 데이터 도움 없이 공급처, 품목, 환율, 제품과 BOM을 등록할 수 있습니다.
- 하나의 제품에 대해 품목별 산출 근거가 포함된 제조원가를 계산할 수 있습니다.
- 제조원가에서 견적가를 만들고 저장할 수 있습니다.
- 저장된 견적은 원본 계산 입력값과 함께 다시 조회할 수 있습니다.
- 필수 입력 누락과 계산 불가능 상태가 명확하게 표시됩니다.

## 후속 검증 질문

- 사용자가 실제 업무에서 가장 자주 누락하는 비용은 무엇인가?
- 마진율과 마크업 중 현장에서 주로 사용하는 방식은 무엇인가?
- 환율은 어떤 출처와 기준 시점을 선호하는가?
- 견적서 출력 형식에서 반드시 필요한 항목은 무엇인가?
- BOM을 직접 입력하는 것과 엑셀 업로드 중 어느 방식이 필수인가?
