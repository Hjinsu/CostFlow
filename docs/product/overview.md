# 제품 개요

## 한 줄 정의

CostFlow는 수입 원재료와 부품의 가격·환율·부대비용 변동을 반영해 제조원가와 견적가를 일관된 기준으로 계산하고 이력을 관리하는 B2B SaaS입니다.

## 배경

수입 원재료를 사용하는 중소·중견 제조사는 공급가격과 환율이 자주 바뀌는 환경에서 원가와 견적을 산출합니다. 실제 업무는 여러 엑셀 파일, 담당자의 경험, 메신저와 이메일에 흩어져 있어 같은 제품도 계산 시점이나 담당자에 따라 결과가 달라질 수 있습니다.

## 제품 목표

- 원가 구성 요소와 계산 근거를 한곳에서 관리합니다.
- 환율과 공급가격 변화가 제품 원가에 미치는 영향을 빠르게 파악합니다.
- 반복 가능한 계산 규칙으로 견적의 정확성과 설명 가능성을 높입니다.
- 계산 결과와 견적 이력을 남겨 이후 비교와 의사결정에 활용합니다.

## 핵심 가치

1. **정확성**: 정해진 계산 기준으로 누락과 수식 오류를 줄입니다.
2. **속도**: 반복 입력과 수작업 취합을 줄여 견적 시간을 단축합니다.
3. **추적 가능성**: 어떤 가격, 환율, 비용, 마진을 사용했는지 기록합니다.
4. **일관성**: 담당자가 달라도 같은 입력에는 같은 결과를 제공합니다.

## 핵심 업무 흐름

`원재료·부품 등록 → 공급가격·통화 입력 → 환율 적용 → 부대비용 반영 → BOM 기반 제조원가 계산 → 마진 적용 → 견적가 산출 → 견적 이력 저장`

## 제품 성공 기준

- 기존 대비 견적 작성 시간 감소
- 계산 근거를 다시 찾는 시간 감소
- 수식 오류와 비용 누락 감소
- 동일 조건에서 계산 결과의 일관성 확보
- 과거 견적과 현재 견적의 비교 가능
