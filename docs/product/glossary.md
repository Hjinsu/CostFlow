# 용어집과 계산 원칙

이 문서는 기획 단계의 공통 언어와 기본 계산 원칙을 정의합니다. 세부 구현 과정에서 변경할 경우 관련 문서와 테스트도 함께 갱신합니다.

## 주요 용어

### 기준 통화

회사 내부 원가와 견적을 표시하는 기본 통화입니다. 초기 기본값은 KRW를 가정하지만 조직 설정으로 관리합니다.

### 구매 통화

공급가격이 표시된 통화입니다. 예: USD, EUR, JPY, CNY.

### 공급가격

공급처가 제시한 품목 단가입니다. 통화, 단위, 적용 시작일과 함께 관리합니다.

### 적용 환율

외화 공급가격을 기준 통화로 환산할 때 사용하는 환율입니다. 통화별 기준 통화 1단위 변환값으로 저장합니다.

### BOM

제품 1단위를 생산하는 데 필요한 원재료·부품과 소요량의 목록입니다.

### 손실률

생산 과정의 폐기, 가공 손실 등을 반영하기 위해 기본 소요량에 추가하는 비율입니다.

### 부대비용

공급가격 외에 조달 과정에서 발생하는 운임, 보험료, 관세, 통관비 등입니다.

### 제조간접비

특정 품목에 직접 귀속하기 어려운 제조 관련 비용입니다. MVP에서는 사용자 입력 금액 또는 단순 배부율을 적용합니다.

### 제조원가

제품을 제조하기 위해 반영한 재료비, 부대비용과 선택적 제조간접비의 합계입니다.

### 마크업률

원가를 기준으로 이익을 가산하는 비율입니다.

`판매가 = 원가 × (1 + 마크업률)`

### 마진율

판매가에서 이익이 차지하는 비율입니다.

`판매가 = 원가 ÷ (1 - 마진율)`

마진율과 마크업률은 결과가 다르므로 화면과 데이터에서 명확히 구분합니다.

### 견적 스냅샷

견적 저장 시 사용한 공급가격, 환율, BOM, 부대비용, 계산 규칙과 결과를 복사해 보존한 기록입니다. 이후 기준 데이터가 바뀌어도 과거 견적은 변경되지 않습니다.

## 기본 계산 원칙

### 외화 단가 환산

`기준 통화 단가 = 외화 공급 단가 × 적용 환율`

환율 방향은 모든 화면과 데이터에서 동일하게 유지합니다.

### 손실률 적용 수량

`적용 수량 = BOM 소요량 × (1 + 손실률)`

예: 소요량 10개, 손실률 5%이면 적용 수량은 10.5개입니다.

### 품목 재료비

`품목 재료비 = 기준 통화 단가 × 적용 수량`

### 부대비용

비용 성격에 따라 다음 중 하나로 적용합니다.

- 정액: 입력 금액을 그대로 반영
- 비율: 지정한 기준 금액에 비율 적용
- 품목 배부: 금액, 중량 또는 수량 기준으로 배부

MVP에서 지원할 배부 기준은 화면·데이터 모델 설계 단계에서 확정합니다.

### 제품 제조원가

`제품 제조원가 = 품목 재료비 합계 + 부대비용 합계 + 제조간접비`

### 견적가

사용자가 선택한 방식에 따라 계산합니다.

- 마크업 방식: `견적가 = 제조원가 × (1 + 마크업률)`
- 마진 방식: `견적가 = 제조원가 ÷ (1 - 마진율)`

마진율은 100% 미만이어야 합니다.

## 반올림과 정밀도

- 내부 계산은 표시 자릿수보다 충분한 정밀도를 유지합니다.
- 중간 단계마다 반복 반올림하지 않고 최종 표시 또는 정책상 필요한 단계에서만 반올림합니다.
- 통화별 표시 자릿수와 조직의 반올림 정책을 분리합니다.
- 견적 스냅샷에는 원본 입력값과 최종 반올림 결과를 함께 보존합니다.

## 이력 원칙

- 공급가격과 환율 변경은 기존 기록을 덮어쓰지 않습니다.
- 계산 결과에는 사용한 데이터의 버전 또는 스냅샷을 연결합니다.
- 수동으로 견적가를 조정하면 조정 전 가격과 사유를 남깁니다.
- 계산 정책이 바뀌면 기존 견적을 소급 변경하지 않습니다.

## 추후 결정 사항

- 운임·보험·관세의 기본 배부 기준
- 제조간접비 입력 및 배부 방식
- 환율 우대율과 안전 환율 지원 여부
- 부가세 포함 여부와 표시 방식
- 단위 변환 규칙
- 제품 수율과 공정별 비용 지원 범위
